So, have you ever had your central air conditioning unit just shut off all of a sudden? If you are a homeowner, this is a incredibly common source of annoyance. In fact, it is the most common reason why people call in a service technician. The culprit is usually that the air conditioner condensate drain line has become blocked.

The solution is straightforward. You need to clean the AC condensate drain line every month. You do this by pouring a quarter cup of vinegar down the line and then flushing it with water. Ideally, you should do this even more frequently to prevent any mold or bacteria from building up. The problem, of course, is that you have to remember to do it, and it is easily forgotten.

This post is a how-to guide to help you configure an off-the-shelf smart Wi-Fi dual water pump to automatically flush out this line on a regular basis, so you never have to worry about it again.

Let's start with the plan. First, you need to flash the device with Tasmota firmware. Second, you need to set up a water reservoir. Third, you need to route the water line to the AC condensate drain line opening, which is usually located near the start of the heating or fan unit. Finally, you need to add rules to manage the water pump timing and notifications.

Moving on to preparing the water pump. I ordered a Wi-Fi dual water pump from Amazon. It is a specific model called the WD-01ADE. There is an image of this device in the blog post; it is a small, white plastic unit designed for home use.

After getting the hardware, I flashed it using the guide provided by the Tasmota community. You can find the link to that specific guide on the blog post. The only tricky part of the physical setup was soldering wires to those tiny connections shown in the guide's image. I ended up following the traces on the circuit board for two of the connections and soldering directly onto those points instead. That gave me a lot more room to work with.

Once the hardware was ready, I flashed it with a tool called Tasmotizer. You can find the link to the Tasmotizer releases on the blog post. After that, you send the Wi-Fi configuration and grab the IP address. At this point, it is crucial to make sure you set the template defined in the guide. You do this by going to the Configuration menu and selecting Configure Other.

There is a specific JSON string you need to paste in there to define the GPIO pins for this pump. You can find that exact code block on the blog post, as it is too technical to read aloud, but it defines the specific pins for the WD-01ADE device.

To help monitor the pump activations, a counter was added. This is useful to keep track of how much water and vinegar mixture is left in the reservoir. This needs to be done after the template was set. You go to Configuration, then Configure Template, and you set GPIO16 to Counter. In the counter drop-down menu, select number one. The nice thing about this is that the value is stored even after a reboot.

Next, let's talk about setting up the water reservoir. You can take a plastic vinegar bottle and poke a hole in it about the size of the fitting you need. After that, you hot glue one of the fittings that came with the water pump supplies into that hole. Be sure to poke a small hole in the top of the bottle so that air can enter, otherwise, it will just suck the air out and stop flowing. There is an image in the post showing the plastic bottle with the fitting hot-glued in place so you can see exactly what it looks like.

Now, for the Tasmota rules. We need to add a rule for when the pump starts. When pump one starts, it should schedule to turn off in thirty seconds. This duration should disperse about one cup of the vinegar and water mixture. It also increments Counter one by one. You can find the specific rule text on the blog post, as it is a command line string. Then, you turn that rule on.

We also need to set the schedule. We want to turn on pump one every day at four in the morning, within a fifteen-minute window. You can find the specific timer configuration command on the blog post. Then, you turn the timers on.

Don't forget to set the timezone of your location. In the example, I used minus eight, but you should use your local offset. You can find the specific command on the blog post.

Lastly, if the device restarts, we need to ensure the water pump relays are off by default. This is not the default behavior in Tasmota firmware. You can find the specific command to set the Power On State to zero on the blog post.

There is a block of code on the blog post that puts all of these commands together so you can copy and paste them easily.

The final result is that you have full control over the pump via the web interface. There is a screenshot in the post showing the Tasmota Web UI with the pump status and settings visible. You can also monitor it via MQTT. For example, the sensor topic will show the time and the current value of Counter one, which in the example screenshot is three, meaning it has run three times.

Looking ahead to future improvements, based on that counter, you could send an alert to notify you to refill the reservoir tank before it runs dry.

And that’s it for this project. You can find all the resources, including the Tasmota template guide, a guide on unclogging AC lines, the Tasmotizer download link, and documentation on the Tasmota Device Manager and Power On State, linked at the bottom of the blog post.
