Hey there. So, quick summary up front: this is a how-to guide on upgrading a Duplicator i3 printer with modern 3D printing parts, firmware, and a bit of creativity. And to be honest, this project was still in progress when I wrote it down.

The Duplicator i3 is a really common 3D printer, but these days, many people consider it outdated. Instead of just throwing mine away and buying a new one, I took on the challenge of upgrading or replacing parts to modernize it. Plus, there are still plenty of resources and parts available out there for this model.

So, here is the to-do list.

First, we need an MKS Gen 1.4 board. This replaces the stock Melzi board. You can find the link on the blog post if you want to buy it.

Next, a RepRap Discount Full Smart Controller. This is the LCD display for the new board. Again, I’ll leave the purchase link on the blog.

Third, a 30 Amp power supply. This replaces the under-powered 20 Amp unit. The link is also available in the post.

We also need a glass bed.

And we need to change the stepper drivers from one-sixteenth to one-thirty-second steps. This provides cleaner and smoother prints. To do that, you need a few specific components and firmware changes.

You will need JST 2-pin to 3-pin adapters for the endstop connectors. You also need to add a JST connector for the extruder stepper.

Then, there are some Marlin Firmware changes.

First, invert the endstops. In the code, this means setting X-Min, Y-Min, and Z-Min endstop inverting to true. This inverts the logic of the endstops.

Second, you need to handle the driver types. You want to uncomment the driver type definitions and replace them with DRV8825 for the X, Y, Z, and second Z axes, while keeping the first extruder as an A4988 and the second extruder as a DRV8825.

Third, double the step count for the DRV8825 drivers from one-sixteenth to one-thirty-two steps. This comes from the previous Marlin configuration. I kept the extruder on an A4988 chip because heat was building up too much on it. You’ll need to calibrate this to 0.84 volts. In the code, this updates the default axis steps per unit to 160 for X and Y, 800 for Z, and 100 for E.

Fourth, invert the X and Y directions, and also invert the extruder direction. In the code, this means setting the invert direction flags for X, Y, and E0 to true.

Fifth, set the Z travel limit. In the code, you define Z max position as 180.

Sixth, enable SD card support by defining SDSUPPORT.

Seventh, add LCD support for that RepRap Discount Full Smart Controller we mentioned earlier. You do this by defining the REPRAP DISCOUNT FULL GRAPHIC SMART CONTROLLER.

Now, a critical note on DRV8825 calibration. The formula is VREF equals rated motor current divided by two. So, a standard NEMA 17 motor is rated at 1.68 amps. Divided by two, that’s 0.84 volts. However, I burned out an extruder stepper following this rule. I dropped it to 0.6 volts. The steppers were less hot, and there was no performance difference.

You also need to replace the display. Be careful here: the connectors are backwards for the standard RepRap Discount Full Smart Controller. Some Amazon reviews pointed this out, so keep that in mind.

You should also replace the power supply. I found a 30 Amp one for about 20 dollars. The current 20 Amp power supply is underpowered, and that’s a known issue with these printers.

Other items on the list include replacing the Y bracket, building an easy access case for the MKS Gen board, adding a filament sensor, and creating a cover and mount for the power supply.

I tested manual LCD bed leveling using mesh bed leveling, manual probing, and LCD bed leveling. I uncommented the LCD assisted bed leveling options. However, I ended up reverting this change.

Instead, we are moving to Auto Bed Leveling using a Z Probe Servo. This involves wiring changes and Marlin configuration.

For the firmware, you need to uncomment specific lines. This includes defining AUTO_BED_LEVELING_LINEAR, setting the number of servos to 3, setting the Z probe servo number to 0, and setting the Z servo angles to 80 and 0. The 80 to 0 angle is important for the servo arm deploy and retraction.

You also use the Z max plug, which I have an extra one for, so it’s used for the switch on the servo arm. Set the Z clearance between probes to 10, the Z clearance multi-probe to 10, and the Z probe low point to negative 10, which is the farthest distance below the trigger point to go before stopping. Enable Z min probe uses Z min endstop pin, and set the Z min probe pin to 19. Pin 32 is the RAMPS default, but we are using an MKS Gen 1.4 board.

There is a command called M280 that is very important here. This controls the servo. You can use this for testing. You can look up the specific values on the Marlin documentation page for G-code M280. Use the values you gather there to set the Z servo angles property.

To test it, you get servo 0 angle using M280 P0. Move servo 0 to a 90-degree angle using M280 P0 S90. Move servo 0 to a 0-degree angle using M280 P0 S0.

You also set the Marlin config of the Z probe offset to negative 1, negative 40, and negative 7.7.

There are other commands to know: M420 gets or sets the bed level state. M119 checks endstop states. And G29 starts the auto bed leveling routine.

If you want to see the full Marlin config difference, you can find that link on the blog post.

So, what did I learn? Well, I learned how to configure and almost build a 3D printer using an existing one as a base. And honestly, I spent way more time on this than I expected.

If you want to dive deeper, there are some great resources. The Marlin firmware website is a must-read. There’s also a specific wiki page for the Wanhao Duplicator i3 on 3dprinterwiki.info. And if you’re curious about the DRV8825 datasheet, Texas Instruments has that available online as well.

I hope this helps if you’re thinking about giving your old printer a new life.
