Duplicator i3 3d printer upgrade. This is a how-to guide on upgrading a Duplicator i3 with modern 3d printer parts, firmware, and creativity. Keep in mind, this project is still a work in progress.

The Duplicator i3 is a common 3d printer that many people now consider outdated. Instead of throwing it away and buying a new one, I took the challenge of upgrading and replacing parts to modernize it. There are also a lot of resources and parts still available for this model.

First, let’s look at the to-do list.

We started with the core components. I replaced the stock Melzi board with an MKS Gen 1.4 board. You can find the link to that part on the blog post. Next, I added a RepRap Discount Full Smart Controller to serve as the LCD display for the new board. You can find the link for that as well. I also swapped out the under-powered 20-amp power supply for a 30-amp unit. You can find the link to that upgrade on the blog post.

Beyond those main purchases, there was a specific list of hardware and software changes. First, I installed a glass bed. Second, I updated the stepper motors to use 1/32 steps instead of 1/16. This provides cleaner and smoother prints. To make this happen, I needed some JST 2-pin to 3-pin adapters for the end stop connectors and added a JST connector for the extruder stepper.

Then came the software changes in the Marlin firmware. This was a big part of the process.

First, I had to invert the end stops. In the configuration file, I set the X, Y, and Z minimum end stop inverting to true.

Second, I defined the driver types. I uncommented the sections for the drivers and set the X, Y, Z, Z2, and E1 drivers to DRV8825. I left the E0 driver as an A4988.

Third, I doubled the step count for the DRV8825 drivers, moving from 1/16 to 1/32 steps. This came from the previous Marlin configuration, which had the default axis steps per unit set to 80, 80, 400, and 100. I updated the default axis steps per unit to 160, 160, 800, and 100. I kept the extruder on the A4988 chip because heat was building up on it too much. I calibrated it to 0.84 volts.

Fourth, I inverted the X and Y directions, as well as the extruder direction. I set invert X direction to true, invert Y direction to true, and invert E0 direction to true.

Fifth, I set the Z travel limit to 180.

Sixth, I enabled SD card support.

Seventh, I enabled LCD support for the RepRap Discount Full Smart Controller.

Next, I dealt with DRV8825 calibration. The formula is VREF equals the rated motor current divided by two. A standard NEMA 17 motor is rated at 1.68 amps. Divided by two, that’s 0.84 volts. However, I burned out an extruder stepper following this. So I dropped it to 0.6 volts. The steppers were less hot, and I didn’t notice a performance difference.

I also had to replace the display. The connectors are backwards for the standard RepRap Discount Full Smart Controller. Some Amazon reviews pointed this out, so be careful.

I replaced the power supply. I found a 30-amp one on Amazon for twenty dollars. The current 20-amp power supply is under-powered. It’s a known issue with these printers.

I replaced the Y bracket.

I made an easy access case for the MKS Gen board.

I added a filament sensor.

I built a cover and mount for the power supply.

I tested manual LCD bed leveling using mesh bed leveling, probe manually, and LCD bed leveling. I uncommented the LCD assisted bed leveling settings, but I ended up reverting this.

Instead, I moved to auto bed leveling using a Z Probe Servo.

This involved several steps. First, the wiring. Second, the Marlin configuration. You can find a video tutorial and the documentation links on the blog post. I uncommented the following lines in the configuration.

I defined auto bed leveling linear. I set the number of servos to 3. I set the Z probe servo number to 0. I set the Z servo angles to 80 and 0. This one is important for the servo arm deploy and retraction. I used the Z max plug because I have an extra Z max to use, so this is used for the switch on the servo arm. I set the Z clearance between probes to 10. I set the Z clearance multi probe to 10. I set the Z probe low point to negative 10, which is the farthest distance below the trigger point to go before stopping. I set Z min probe uses Z min endstop pin to true. And I set the Z min probe pin to 19. Pin 32 is the RAMPS default, but we are using an MKS Gen 1.4 board.

There are a few important G-code commands to remember. M280 is important! This controls the servo. You can use this for testing. The link is on the blog post. Use the values gathered here to set the Z servo angles property. To get servo 0 angle, use M280 P0. To move servo 0 to a 90-degree angle, use M280 P0 S90. To move servo 0 to a 0-degree angle, use M280 P0 S0.

I set the Marlin configuration of the Z probe offset to negative 1, negative 40, and negative 7.7.

M420 is used to get or set the bed level state. You can find the link on the blog post.

M119 shows the endstop states.

G29 starts the auto bed leveling routine.

You can find the full Marlin config difference on the blog post.
