Part two of hacking my Sony A6000 camera.

Welcome back. This is a smaller continuation of the previous blog post where I started hacking the Sony A6000. I’ll be coming back with more updates, but for now, let’s dive into this second part.

There is an image here that shows the Sony A6000 paired with a 16-50mm lens. It’s a clean, straightforward shot of the camera body, highlighting the compact design that makes it such a popular choice for enthusiasts.

First up, we have free apps. To install a time-lapse function and an FTP uploader, along with some additional hacks, I looked to an open-source project that turned out to be absolutely awesome. You can find the link to this project on the blog post. Once you have that, you download the executable from the releases section, and it will guide you through installing the necessary applications onto the camera. I would also strongly recommend the OpenMemories Tweaks app. It’s great because it allows you to change some of the internal limits on the camera, unlocking extra functionality.

Next, let’s talk about the USB-C battery hack. Batteries drain very quickly with this camera. The stock battery is around 1020 milliampere-hours. Swapping out batteries is common and honestly quite tedious. Getting USB-C versions of these batteries helps with charging on the go, which you can find linked on the blog post, but it’s still annoying to have to deal with cables.

So, after a bit of hacking, I took the power adapter version of this setup, which is also available for purchase via the link on the blog post, and I bundled everything up into a single battery shell with a USB-C female tail. You can find the link for that specific USB-C part on the post as well. Nothing super clever happened here; I just took apart the USB 5-volt to 8-volt adapter and added that circuitry to the shell with a USB-C input. The idea is to use a large battery bank when taking very long time-lapses. The next step in this process is building a battery pack on the bottom of the camera.

To give you a clear idea of what I used for this build, here is the gear list. First, I used USB-C NP-FW50 batteries, which serve as rechargeable on-the-go batteries. Second, I used the AC-PW20 power adapter, which acts as a dummy battery, and I cannibalized it for the shell. Third, I attached a USB-C female tail, which provides the input for the external battery bank. And fourth, I keep a SanDisk Extreme SD card reader handy for fast on-the-go card dumps. All of these items are linked on the blog post if you want to grab them.

There is also a video on the blog post that shows you the build process for the power adapter in action.

Moving on to data transfer hurdles. This is a follow-up from my previous post.

One method is using a card reader. On the go, I keep a card reader near the camera bag. It allows the SD card to be plugged directly into a computer or phone in a small package. Sometimes I just need a few pictures on my phone to edit and send, and all the other files get dumped later.

Another method is using the FTP uploader within the camera. This idea is great, but it’s very slow. I measured it at about 70 files in 13 minutes for full-resolution JPEG files. If there aren’t a lot of pictures, this makes sense. But typically, taking the SD card out and data dumping is still much quicker.

Using the FTP uploader app mentioned above, I use a specific bit of Python code to dump the files into a directory I care about. You can find the reference to this command and the specific Python module on the blog post, which points to a one-line FTP server setup in Python. It’s a simple script that sets up the server, allowing the camera to push those files over just like a standard FTP transfer.
