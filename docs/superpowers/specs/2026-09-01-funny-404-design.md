# Funny 404 Page — Design

## Summary

Replace the current minimal 404 page (`src/pages/404.astro`) with a broken-hardware gag
that matches the site's DIY-maker voice, includes a real cold-solder-joint photo, and offers
four escape routes (Home, About, EPUB, RSS).

## Current state

`src/pages/404.astro` is 27 lines: "Page not found" heading, one muted sentence, and 3
links (Home / All posts / About). No image, no humor.

## Design

### Layout (top to bottom, centered, `max-w-xl`)

1. **Image** — cold-solder-joint macro photo, rounded corners, `max-width: 480px`,
   responsive (`w-full`). Served as `<picture>` with a WebP `<source>` and JPEG fallback,
   matching the existing pattern in `src/layouts/PostLayout.astro:179-190`.
2. **Image credit** — small muted caption below the image:
   `Photo: Coronium / Wikimedia Commons (CC BY-SA 3.0)` with a link to
   `https://commons.wikimedia.org/wiki/File:Cold_solder_joint.jpg` (satisfies CC BY-SA attribution).
3. **Heading** — `404 — Connection Reset by Hardware`
4. **Joke line** — `This page hit the same fate as my first PCB: a cold solder joint. It looked fine, but it wasn't making contact.`
5. **Escape routes** — 4 links in a row, mono font, accent color, hover-underline (matching
   existing link style): Home (`/`), About (`/about/`), EPUB (`/blog.epub`), RSS (`/rss.xml`).

### Styling

- Reuse existing CSS custom properties: `--color-text`, `--color-text-muted`, `--color-accent`.
- Keep the site's existing container/centering conventions (`container mx-auto px-4 py-24 text-center`).
- No new dependencies, no new global CSS, no layout or config changes.

## Image sourcing

- **Source:** `File:Cold solder joint.jpg`, Wikimedia Commons, 700×520, CC BY-SA 3.0,
  photographer Coronium.
- **Download to:** `public/images/cold-solder-joint.jpg`
- **WebP twin:** run the existing `scripts/optimize-images.py` (resizes to max 900px wide —
  this image is under that so no downscale — and writes `cold-solder-joint.webp` alongside,
  quality 82). This matches how every other image on the site is stored/served.
