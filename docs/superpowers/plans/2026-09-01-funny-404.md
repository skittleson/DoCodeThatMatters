# Funny 404 Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the minimal 404 page with a broken-hardware gag (cold-solder-joint photo + joke + 4 escape links).

**Architecture:** One Astro page rewrite (`src/pages/404.astro`) plus one new image asset
(`public/images/cold-solder-joint.jpg` + generated `.webp` twin). No new dependencies, no
config changes, no other files touched.

**Tech Stack:** Astro 7 (static), existing `BaseLayout`, existing WebP optimization script
(`scripts/optimize-images.py`), existing CSS custom properties.

## Global Constraints

- Do NOT add new npm dependencies.
- Do NOT change routing, config, or any file other than the two listed per task.
- Reuse existing CSS custom properties: `--color-text`, `--color-text-muted`, `--color-accent`.
- Image must be served as `<picture>` with a WebP `<source>` and JPEG fallback (matches
  `src/layouts/PostLayout.astro:179-190`).
- CC BY-SA 3.0 attribution is required on the page (photographer name + license link).
- Build gate: `npm run build` must pass before committing. NOTE: this build occasionally hits
  a transient Wikimedia 429 during the EPUB image-download step; if that specific step fails,
  retry the build once before concluding it's broken.
- Commit message style: `feat:` (see git log for examples).

### Task 1: Add the cold-solder-joint image asset

**Files:**
- Create: `public/images/cold-solder-joint.jpg`
- Create: `public/images/cold-solder-joint.webp`

**Interfaces:**
- Produces: two static files at the paths above, both resolvable at `/images/cold-solder-joint.jpg`
  and `/images/cold-solder-joint.webp` in the built site.

- [ ] **Step 1: Download the source image from Wikimedia Commons**

```bash
curl -sL "https://upload.wikimedia.org/wikipedia/commons/a/a0/Cold_solder_joint.jpg" \
  -o public/images/cold-solder-joint.jpg \
  -H "User-Agent: DoCodeThatMatters/1.0 (personal blog; contact docodethatmatters@outlook.com)"
```

Verify it landed as a valid JPEG:

```bash
file public/images/cold-solder-joint.jpg
```

Expected: `JPEG image data ... 700x520`

- [ ] **Step 2: Generate the WebP twin using the existing optimization script**

```bash
python3 scripts/optimize-images.py
```

This script scans `public/images/`, skips files it has already converted, and writes
`cold-solder-joint.webp` alongside the original (resizes to max 900px wide — this image is
700px so no downscale — quality 82). Confirm the new file exists:

```bash
ls -la public/images/cold-solder-joint.webp
```

Expected: a non-zero-size `.webp` file.

- [ ] **Step 3: Commit**

```bash
git add public/images/cold-solder-joint.jpg public/images/cold-solder-joint.webp
git commit -m "feat: add cold-solder-joint image for 404 page"
```

### Task 2: Rewrite the 404 page

**Files:**
- Modify: `src/pages/404.astro` (full rewrite)

**Interfaces:**
- Consumes: `/images/cold-solder-joint.jpg` and `/images/cold-solder-joint.webp` from Task 1;
  existing `BaseLayout` (`src/layouts/BaseLayout.astro`) which accepts a `title` prop.
- Produces: the built `docs/404.html` (flat file, GitHub Pages custom-404 mechanism — already
  verified working in production).

- [ ] **Step 1: Rewrite `src/pages/404.astro`**

Replace the entire current file with:

```astro
---
import BaseLayout from '../layouts/BaseLayout.astro';

const links = [
  { href: '/', label: 'Home' },
  { href: '/about/', label: 'About' },
  { href: '/blog.epub', label: 'EPUB' },
  { href: '/rss.xml', label: 'RSS' },
];
---

<BaseLayout title="Page not found — Do Code That Matters">
  <main class="container mx-auto px-4 py-24 text-center max-w-xl">
    <figure class="mb-8">
      <picture>
        <source type="image/webp" srcset="/images/cold-solder-joint.webp" />
        <img
          src="/images/cold-solder-joint.jpg"
          alt="A cold solder joint on a circuit board"
          width="700"
          height="520"
          class="rounded-md w-full max-w-[480px] mx-auto object-cover"
          loading="eager"
        />
      </picture>
      <figcaption class="mt-2 font-mono text-xs" style="color: var(--color-text-muted);">
        Photo:
        <a
          href="https://commons.wikimedia.org/wiki/File:Cold_solder_joint.jpg"
          style="color: var(--color-accent);"
          class="hover:underline"
          target="_blank"
          rel="noopener"
        >
          Coronium / Wikimedia Commons (CC BY-SA 3.0)
        </a>
      </figcaption>
    </figure>

    <h1 class="text-3xl font-bold mb-4" style="color: var(--color-text);">
      404 — Connection Reset by Hardware
    </h1>
    <p class="font-mono mb-8" style="color: var(--color-text-muted);">
      This page hit the same fate as my first PCB: a cold solder joint. It looked fine, but it
      wasn't making contact.
    </p>

    <nav class="flex justify-center gap-6 font-mono text-sm">
      {links.map((l) => (
        <a href={l.href} style="color: var(--color-accent);" class="hover:underline">
          {l.label} &rarr;
        </a>
      ))}
    </nav>
  </main>
</BaseLayout>
```
