Linux Wifi Hotspot with PiHole. This post is still a work in progress, so come back for updates.

Here is the TLDR. You can use an Alfa AC1900 WiFi Adapter to broadcast the hotspot. This adapter serves as a long-range dual-band 802.11ac hotspot access point. If you want to buy one, you can find it on Amazon.

Next, we look at the starting script, which is called onstart.sh. This script disables power saving on the wireless interface, sets the transmit power to a fixed level, switches the USB mode for the specific driver, and then launches the create_ap tool in daemon mode. It configures the network to use a specific IP range for DHCP, sets the country to the US, and enables various advanced Wi-Fi capabilities like 802.11n and 802.11ac on the 5-gigahertz band. It creates a network named TestNetwork with the password testing123.

Moving on to the next section: Disable IPv6. To do this, you need to edit the sysctl.conf file. Inside that file, you add three lines of configuration to disable IPv6 for all interfaces, the default interface, and the loopback interface.

Then, we move to installing and configuring Pi-hole. You run a command that downloads the installation script from Pi-hole’s official website and executes it, skipping the operating system check. After that, you need to set up the DHCP server to use the 192.168.12.1 address range.

Finally, for resources, there is a link to a GitHub repository called linux-wifi-hotspot by lakinduakash, which contains scripts and documentation related to this setup. You can find that link in the blog post.
