Let's jump right into the short version. We are using an Alfa AC1900 WiFi adapter to broadcast the hotspot. You can find the link to that specific adapter on the blog post.

Here is a quick breakdown of the components. First, you have the Alfa AC1900 WiFi adapter. Its purpose is to act as a long-range, dual-band 802.11ac hotspot access point, and you can purchase it from Amazon.

Next, we have the starting script. There is a file called onstart.sh that runs when you boot up. Since I cannot read the actual code block verbatim, I'll just tell you that you should check out that script on the blog post to see exactly how it configures the interface and launches the access point daemon with your specific network settings.

After that, we need to disable IPv6. You would open your sysctl configuration file using a text editor. There are three lines you need to add or verify there. First, set net dot ipv6 conf all disable ipv6 to 1. Second, set net dot ipv6 conf default disable ipv6 to 1. And third, set net dot ipv6 conf lo disable ipv6 to 1.

Then, we move on to installing and configuring Pi-hole. There is a one-line command in the blog post that downloads and runs the installer. You can find that exact command on the blog post. Once that is done, you need to make sure your DHCP server is set up to use the 192.168.12.1 range.

Finally, for resources, there is a link to a GitHub repository called linux-wifi-hotspot that contains more detailed scripts and documentation. You can find that link on the blog post as well.
