Part two of hacking my Sony A6000 camera.

So, this is a smaller continuation of the previous blog post where I talked about hacking this specific Sony A6000 camera. If you missed that one, or if you want to catch up on the earlier updates, you can head back to the main blog post to see the full series.

First things first, let's talk about some free apps. To get a time-lapse feature and an FTP uploader working on this camera, along with a few other little hacks, I used an open-source project that was absolutely awesome. You can find the link to that project in the blog post itself. Once you download the executable from the releases section, it walks you through installing the various applications onto the camera. I would also highly recommend checking out an app called Open Memories Tweaks. This one is great because it allows you to change some of the internal limits on the camera, unlocking a few extra capabilities.

Now, let's move on to the USB-C battery hack. You know, batteries drain very quickly with this camera. The stock battery only has about 1020 milliamp hours. Swapping out batteries is common but it gets tedious fast. I found that getting USB-C versions of these replacement batteries helps a lot with charging on the go, but honestly, dealing with separate cables is still annoying.

So, after doing a bit of hacking with the power adapter version of this setup, I decided to bundle everything up into a single battery shell with a USB-C female tail attached. Nothing super clever here, really. I just took apart the USB 5-volt to 8-volt adapter and added that circuitry into the shell with a USB-C input port. The whole idea behind this is to allow me to use a large battery bank when I'm taking very long time-lapse sequences. My next big idea is to build a dedicated battery pack for the bottom of the camera, but for now, here is the build for the power adapter. You can find links to the specific parts I used in the blog post, but basically, I’m using USB-C NP-FW50 batteries for on-the-go recharging, cannibalizing an AC-PW20 power adapter for the shell, adding a USB-C female tail for the external power input, and using a SanDisk Extreme SD card reader for fast data dumps.

There is also a video demonstrating this setup in the blog post, so you can see exactly how it looks and works if you are interested in the visual aspect of the build.

Moving on to some data transfer hurdles. This is a follow-up from my previous post, but I ran into some issues moving files around.

First, using a card reader. On the go, I keep this specific card reader near my camera bag. It allows me to plug the SD card directly into a computer or a phone in a small, compact package. Sometimes I just need a few pictures on my phone to do some quick edits and send them off. In those cases, I pull the card, dump what I need onto the phone, and then I dump all the other files afterward.

Second, using the FTP uploader within the camera. The idea of using the FTP uploader is great in theory, but in practice, it is very slow. For example, transferring 70 full-resolution JPEG files took about 13 minutes. If you are only moving a few pictures, that makes sense and is convenient. But if you have a lot of images, taking the SD card out and doing a direct data dump is going to be much quicker still.

When I do use the FTP uploader app mentioned earlier, I use a bit of Python code to handle the transfer. Specifically, I run a one-line command that starts an FTP server locally to pull the files into the directory I care about. You can find the exact Python command and a reference link to explain how it works in the blog post, but essentially, it sets up a quick local server for me to grab the images without having to dig through menus on the camera.
