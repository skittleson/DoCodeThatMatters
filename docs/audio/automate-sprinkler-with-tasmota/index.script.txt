A simple water sprinkler system for makers

Homeowners often find that over-the-shelf sprinkler systems can be difficult to use and lack customization options. They may also be outdated and may not be as efficient for water or power usage as desired. The "set it and forget" mentality is not always the best approach. It may be worth considering more customizable and efficient options for your home's sprinkler system.

Project Research

Want to improve your home's sprinkler system without breaking the bank? One solution is to use a combination of inexpensive hardware and customizable open-source software. This approach allows for flexibility and the ability to add additional features as needed. The main goal is to trigger the water sprinkler solenoid to turn on or off based on specific conditions such as time, including sunrise and sunset, humidity, and temperature. By implementing this method, you can achieve better results with low effort.

Just a small note here: there are affiliate links on the blog post for hardware used in this project, so you can find those links there if you are interested in buying the exact parts.

Must Haves

Let's look at the requirements. The things that absolutely must be included are:
First, the IoT device needs to run when the internet is down or the network is down.
Second, it needs timer-based watering, with support for sunrise and sunset times.
Third, there needs to be a way to manually toggle the watering state.
Fourth, there must be a way to back up and restore settings.
And finally, as a future improvement, we want the system to check if it is sunrise or sunset, but only start watering if the temperature allows it. This is to prevent freezing of plant roots.

Wants

Now for the nice-to-haves:
First, we want to measure water time, humidity, and temperature. All off-the-shelf sprinklers do this with various features.
Second, local network control with no data submitted to a third party.
Third, graphing and the ability to analyze the data.
Fourth, watering runaway protection.
Fifth, if humidity is at a certain percentage, skip watering today. Most over-the-shelf sprinklers do this.
Sixth, if the weather forecast is rainy, skip watering. It should also notify me when this occurs. Most off-the-shelf sprinklers can do this sort of thing.
Seventh, send a notification to any platform I want, like AWS, Gmail, IFTTT, or Alexa.
And eighth, a moisture sensor.

Hardware

At the lowest level, the IoT hardware should be able to do the following:
Toggle power on and off.
Report power state, humidity, and temperature.
Not require an internet connection.
And customize power toggling based on special conditions.

A twenty-dollar US over-the-shelf Sonoff hardware device does three of those four things easily. The fourth point needs to have special programming. There are multiple options out there, but this fulfills the need of an "over-the-shelf" device that can be used with open-source software. You can see a photo of the Sonoff device on the blog post.

The easiest way to wire this up is using an existing extension cord. Cut into it, then follow the directions in the Sonoff wiring guide. Plug one into the 24 VAC power supply of an existing water sprinkler adapter. You can find the link to the power supply on the blog post.

Alternative hardware that I ended up using includes a few specific components:
First, an ESP8266 microcontroller. This is a WiFi MCU that runs Tasmota.
Second, an OLED screen for a status display of the sprinkler state.
Third, a solid-state relay to switch the 24 VAC sprinkler valve.
And fourth, a BME280 sensor, which measures temperature, humidity, and pressure. This helps skip watering when it is too cold or humid. You can find links to buy all of these components on the blog post.

You can view images on the blog post showing a 3D rendering of the sprinkler PCB and a photo of the actual printed circuit board.

Software

The device can be flashed with open-source software called Tasmota. I prototyped with the Arduino IDE for a while, but Tasmota seems safer with the features needed. So I won't go into too much detail, but Tasmota solves the following problems:
It is local network controlled.
It runs even when the internet is down.
It is highly customizable and battle-tested for years.
It has simple programming.
And it offers multiple ways of interacting, such as command line, MQTT, and a web UI.

You can find a video on the blog post on how to flash and set up the device when you get it. This is really common with this device.

Wiring and Module Parameters

Here are the wiring connections needed:
Pin D2, or GPIO 4, connects to I2C SDA.
Pin D1, or GPIO 5, connects to I2C SCL.
Pin D5, or GPIO 14, connects to Relay 1.
And Pin D0, or GPIO 16, connects to Counter 1.

Setup Time

Using the Tasmota Web Console command line, we need to set up the time.
First, set PowerOnState to 0. This means if there is a power outage or reset, default the power state to off.
Next, set your time zone using standard GMT offset, for example, minus 8. Note that this doesn't account for daylight savings time. You can see the documentation on the Tasmota website for more details.
Test your time by typing the command "time".
Update your location. You can use a website like latlong.net to find your coordinates.
Run the command "Latitude" followed by your specific latitude value.
Run the command "Longitude" followed by your specific longitude value.
Run the command "STATUS 7" to see sunrise and sunset with local time. Ensure it is the actual time.

Setup Timers

Using the Tasmota Timer Web UI, four timers will be created. Two timers for starting and stopping the watering at sunrise. Two timers for the same at sunset.

The settings for these timers are quite specific, so I recommend looking at the blog post to copy the exact configuration strings for Timer 1 through Timer 4. Essentially, Timer 1 and Timer 3 handle the start times for sunrise and sunset respectively, while Timer 2 and Timer 4 handle the stop times.

Once the timers are set, turn them on. It is also adjustable in the Web UI. You can see an image on the blog post showing the Sunrise Starting Timer configuration.

To stop the watering, Timer 3 has a 20-minute offset. This allows for 20 minutes of watering. Do the same for Timer 4 for sunset. According to the Tasmota docs, when Mode 1 or Mode 2 is used, Latitude and Longitude become available. In that case, the Time value is always used as an offset, so make sure to set it to zero zero colon zero zero if no offset is wanted. You can see an image on the blog post showing the Sunrise Stopping Timer configuration.

Using the Tasmota Web Console command line, you can type in the timer names to verify the settings.

Runaway Protection

We have a few layers of protection here:
First, Timer 2 and Timer 4 should stop the sprinkler.
Second, the system never runs more than 1320 seconds, which is 22 minutes, when the power state is on. This is handled by a specific rule in Tasmota. You can find the exact code for this rule on the blog post, as it is best to copy and paste it directly into your device's console.
Third, use Node-RED to trigger a power state off if receiving specific MQTT messages. This could be adapted to turn off timers when the weather is expected to rain.
And finally, monitor on and off times using Grafana. I have prototyped using alerts with a Telegram integration in case all else fails.

Extending to other Platforms (Optional)

Using a simple flow in Node-RED, I have added support for a UI and Alexa control, with tracking usage via Grafana. Using the MQTT message for the sensor, the data is formatted and sent to a local Grafana instance on a Raspberry Pi. You can find the link to the Grafana installation tutorial on the blog post.

You can see images on the blog post showing Node-RED with Alexa support, the Node-RED UI, and Grafana dashboards tracking the ON/OFF state of Tasmota MQTT messages over time, including a 7-day view.

Setup Rules (Optional)

Here are two more timers, or rules, that are wanted for future work:
First, before sunrise, check the temperature. If it is too cold, send an MQTT message and disable start timers.
Second, before sunrise, check the humidity. If it is raining, then disable the timer.
