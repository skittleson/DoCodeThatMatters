This post will show you how to save messages from a public endpoint to your backend using AWS Lambda, AWS S3, and Google Recaptcha. I originally wrote the gist for myself, but I had enough requests that I decided to share it in a blog post. Feel free to copy and paste whatever works for you.

Let’s start with the request from the frontend source. You’ll want to add some specific code to your frontend index dot html file, or wherever your form is being sent from. First, you need to replace the placeholder reCAPTCHA site key with a real one from your own account. The code involves loading the Google reCAPTCHA API script and then using a script block to execute the captcha. Inside that script, you’ll be readying the captcha, executing it with a specific action like homepage, and then handling the resulting token. If you want to dive deeper into how this works, you can find the documentation on the Google Developers site under their reCAPTCHA version three guides.

Now, let’s talk about the backend setup. You need to start by creating an AWS Lambda function that has access to add items to S3. We are using a node dot js or JavaScript lambda function for this. There are three environment keys you need to set up inside that function.

First is the Google Recaptcha Key, which you can get from the Google Developers reCAPTCHA console.
Second is the Message Bucket, where you will create a bucket in AWS S3 to store your data.
Third is the SNS Topic ARN, where you should create an SNS topic to receive emails or SMS notifications to your phone.

Once that is set up, you can find the full Lambda function code in the blog post itself. It handles verifying the captcha token and saving the JSON object to S3.

Finally, we need to set up the API Gateway. There are a few specific steps here.
First, create an AWS API Gateway API with a resource named form and add a POST method to it.
Second, set the integration type to Lambda Function.
Third, make sure to check the box for using Lambda Proxy integration.
And fourth, select the specific Lambda function you created earlier from the list.

That’s the complete setup for saving JSON objects to S3 with recaptcha verification.
